# Rewrite 验证记录

## 本次自动验证

当前工作区在 Linux 上通过 148 项测试：核心单元测试 124 项、核心集成测试 1 项、CLI 9 项、GUI 中可跨平台执行的模型测试 14 项。新增 Debug 输出的验证范围见 [GUI Debug 输出验证记录](debug-output-validation.md)。

```sh
cargo test --workspace --features stt-gui/native-gui
cargo fmt --all --check
cargo clippy --workspace --all-targets --features stt-gui/native-gui -- -D warnings
cargo clippy --workspace --all-targets --target x86_64-pc-windows-gnu --features stt-gui/native-gui -- -D warnings
cargo build --workspace --target x86_64-pc-windows-gnu --features stt-gui/native-gui
```

本次 Windows 构建完成 CLI、GUI 的开发版编译与链接，未启用 `static-libav`。未重建静态 FFmpeg 发布包，也未向真实服务商发送付费请求。用户曾反馈此前版本在 Windows 整体测试中未见异常，随后报告 EmEditor 和 VS Code 的 UI Automation 选区读取失败。本次改为剪贴板复制读取，以下自动测试与交叉编译均已通过；新的原生剪贴板读取、备份恢复和退出等待流程尚未进行 Windows 实机验收。

已覆盖的行为：

- 老配置缺少 `REWRITE` 时的默认值、提示词 ID 与配置往返、重复 ID 和非法 JSON 拒绝。
- 八种 Provider 的路由、认证头、提示词与输入、模型覆盖，以及 Google 的 URL 模型。
- 对象递归合并、数组替换、嵌套对象中的 null 删除、数组中的 null 保留；Audio multipart 与 Rewrite 共用合并规则。
- JSON/SSE 文本提取、忽略推理内容、完成事件、服务端错误、流意外结束不返回部分文本。
- JSON/SSE 拒绝服务端明确标记的长度截断、过滤、工具调用和暂停等非最终结果，后续 `[DONE]` 或 `message_stop` 不会覆盖失败。七个非 Responses Provider 的 14 个 HTTP 响应场景均验证了返回错误且不自动重试；正常终止及缺失、未知原因的兼容性也有覆盖。
- 本地 HTTP 模拟服务：总尝试次数、永久错误不重试、连接测试只请求一次、SSE 服务错误重试、退避和响应体等待期间取消、2 MiB 响应上限、错误详情中的密钥隐藏。
- 失败、空结果、取消和关闭后的迟到结果不调用输出，即使开启失败占位提示；成功只调用一次输出，不改变音频重试缓冲。
- 录音、暂停、上传、Rewrite 期间拒绝新的 Rewrite/连接测试/配置保存；连接测试的取消与清理完成前保持任务锁。
- 保存忙碌或文件写入失败时保持原配置；正常保存后文件与运行时一致。
- 使用可控注册器模拟启动注册失败，以及更换与回滚注册均失败，验证之后保存有效组合能恢复热键；再次注册失败时保留磁盘和运行时配置。从未请求启用热键的运行方式不会因保存而启用热键。这些测试不调用 Windows 全局热键 API。
- 快捷键别名、Prompt 间及与音频操作的冲突、Hook 模式额外修饰键产生的冲突。新增两项测试覆盖：配置 Rewrite 后，RegisterHotKey 模式拒绝任意音频动作或提示词占用单独的 `Ctrl+C`（包括等价别名）；Hook 模式及无 Rewrite 配置保留原有行为。
- 16 项选区读取事务测试：成功后恢复文本与自定义格式、复制内容与原剪贴板相同时仍接受、不复用旧文本、空白或超长文本、复制/读取/备份错误、等待松键、不同阶段取消、焦点变化，以及取消时仍报告恢复失败。另覆盖共用等待参数的默认值、自定义值和零值，复制前等待期间取消或切换焦点不发送复制，以及恢复等待期间取消仍完成配置的等待时间。使用可控模拟后端，不等同于 Windows 剪贴板格式或 `SendInput` 的实机验证。

## Windows 人工验收清单

此前整体测试反馈不涵盖本次剪贴板读取变更，以下项目仍需逐项实机验证。

1. 在 Windows 10/11 的 EmEditor、VS Code、记事本、浏览器文本框和 Word 中选中文本，分别使用剪贴板和 SendInput 写入模式改写；两种模式均应通过 `Ctrl+C` 读取。记录应用版本，分别验证普通权限、双方管理员权限及目标应用权限高于 Dictate 的场景；受权限限制时不得发送旧剪贴板文本。
2. 验证无选区、只读文本、密码框、禁用复制或自定义 `Ctrl+C` 的控件，以及读取期间切换窗口/控件。读取失败或没有新的非空白文本时不发送请求、不写入；无选区时结果遵循应用 Copy 行为，例如 VS Code 可能复制当前行，不能以“未选中”统一预期失败，也不能假定本程序能识别密码框。
3. 请求超时、401、429、5xx、空结果、非法 JSON、SSE 中途断开，以及 `length` / `max_tokens` / `MAX_TOKENS` 截断：失败前不输出部分结果，失败后不输出占位文本；分别验证失败提示开关开启与关闭。
4. 原剪贴板分别放入空内容、文本、HTML/RTF、图片和文件列表，验证成功、复制失败、取消及读取期间退出时均尝试恢复；请求只能在恢复成功后开始。测试超过 64 MiB、超过 256 种格式或不支持备份的格式应在清空前拒绝。模拟剪贴板占用和恢复失败，确认错误不被取消消息掩盖；检查松键等待、延迟复制及恢复后是否被迟到复制覆盖。修改 Paste delay 和 Restore delay，确认 Rewrite 读取共用这两个值；开启 SendInput 后两个字段仍可编辑，读取等待仍生效，音频写入行为保持不变。
5. 在选区读取、请求、退避、写入等待阶段取消，随后启动新任务。确认输入读取清理完成前保持互斥，退出等待原生工作线程恢复剪贴板；迟到结果不写入。写入已开始后的行为遵循原有输出通道限制。
6. 录音、暂停、转写、Rewrite、连接测试期间连续触发其他任务：不并发、不排队。任务结束后 Retry 只重发上一段音频。
7. 两个 API 页面的连接测试使用当前草稿；Rewrite 测试不读取选区、不回填。测试期间关闭设置窗口或退出程序，确认取消、清理和重新打开窗口行为正常。
8. 提示词增删改、排序、编辑窗取消、设置取消、保存与重启；确认 ID 和快捷键仍对应正确提示词。分别在 Hook 与 RegisterHotKey 模式下录入、长按、松键和切换焦点。配置 Rewrite 后，RegisterHotKey 模式应拒绝音频或 Rewrite 的单独 `Ctrl+C` 绑定；Hook 模式允许该组合，注入的复制事件不得再次触发 Rewrite。
9. RegisterHotKey 模式下占用一个新快捷键，使保存失败：文件和运行时保留旧配置、旧快捷键继续工作；关闭程序不能卡在热键线程退出。另在启动注册失败、回滚注册失败后改用可用组合保存，确认无需重启即可恢复录音与 Rewrite 快捷键。
10. Provider 下拉的鼠标、方向键、Enter、Esc、Tab；提示词多行输入的 Enter、Tab 和快捷键录入。检查中、英、德、日、法五种语言及跨显示器 DPI 切换后的布局。
11. 在实际服务商上测试八种 Provider 的 JSON/SSE 响应、认证、Base URL 补全与嵌套额外参数。自动化测试只验证本地协议行为。
